# Zodiac Fonts Free

**55 Astrology Glyphs — Regular Sans-Serif**

High-quality, free astrology glyphs for modern design and spiritual projects.

## What's Included
- 1 professional OpenType font (`.otf`)
- 1 web-optimized webfont (`.woff2`)
- 55 SVG vector files
- License and documentation

## Folder Structure
- `fonts/otf/`          → Desktop design software (Illustrator, Figma, Photoshop, etc.)
- `fonts/webfonts/`     → Self-hosting on websites
- `svgs/sans-regular/`  → Individual vector glyphs (Regular sans-serif)

## Installation

### Desktop Font (.otf)
**macOS**: Double-click the `.otf` file → **Install Font**  
**Windows**: Right-click the `.otf` file → **Install**

### Web Font (.woff2)
Copy the file from `fonts/webfonts/` and use it with `@font-face` in your CSS.

### SVG Glyphs
Use the files from the `svgs/sans-regular/` folder directly in Figma, Adobe Illustrator, HTML, or any design tool.
